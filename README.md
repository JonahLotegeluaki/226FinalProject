## Organization
This java project is organized with Maven.
All following commands are within `FinalProject/`.
A makefile is included for convience commands.
Build: `mvn compile` (or `make`)
Run: `java -cp target/classes Main`
Build & Run: `make run`
Test: `mvn test`
Build & Test: `make test`
## Design
This is a GUI-based application, implemented using the Model-View-Controller design framework.
