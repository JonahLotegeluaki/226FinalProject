# Setup
Pull with `git clone https://github.com/JonahLotegeluaki/226FinalProject.git`, or with `gh repo clone JonahLotegeluaki/226FinalProject`.
## Dependencies
- JDK (version 21 LTS)
- Maven build system

To test build system, use `make run` or:
```
$ mvn compile
$ java -cp target/classes Main
```

No other setup is needed other than pulling the repository and installing the required dependencies.

## Demo
To run the demo with sample data, it first must be generated by running the test `structures/AppDataTest.writeSampleData()`. Do this with `mvn test`. It will generate the file `FinalProject/sample_data.json`, which is in `.gitignore`.
