# Setup
Pull with `git clone https://github.com/JonahLotegeluaki/226FinalProject.git`, or with `gh repo clone JonahLotegeluaki/226FinalProject`.
## Dependencies
- JDK (version 21 LTS)
- Maven build system

To test build system, use `make run` or:
```
$ mvn compile exec:java -Dexec.mainClass="Main"
```

No other setup is needed other than pulling the repository and installing the required dependencies; maven will handle downloading packages.

## Demo
To run the demo with sample data, it first must be generated by running the test `structures/AppDataTest.writeSampleData()`. Do this with `mvn test`. It will generate the file `FinalProject/sample_data.json`, which is in `.gitignore`.
You can then run the program and load the data with `File -> Open`.

### Custom Graph
If you would like to build a custom hospital graph into the sample data, you need to provide it and then enable a specific test.
First, create `FinalProject/graph.csv`, and input the nodes connections between nodes there (see `FinalProject/sample_graph.csv`).
Then, run the special test with `mvn test -DcustomGraph=true`. This will produce `FinalProject/custom_data.json`, which you can then load and use in the program.
