# Contributing
Pull with `git clone https://github.com/JonahLotegeluaki/226FinalProject.git`, or with `gh repo clone JonahLotegeluaki/226FinalProject`.

## Branching
All features developed will reside on a branch from `master`.
Name the branch `category/name_of_change`. Categories:
- `feature`: General feature.
- `gui`: Changes to the GUI.
- `fix`: Fix functionality.
Merge from `master` regularly.
All development must happen on branches.
## Pull Requests
Open a pull request when changes are complete.
To be accepted, the branch must compile and pass all tests, including ones for the new behavior.
